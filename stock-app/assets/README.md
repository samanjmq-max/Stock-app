# assets/

Acá van los assets "fuente" (logo en SVG editable, ilustraciones,
capturas para el README) que NO se sirven directamente al navegador.
Los assets que sí debe poder pedir el navegador (íconos de la PWA,
favicon) van en `frontend`-style dentro de `public/`, que es la
convención de Next.js para archivos estáticos servidos tal cual.
